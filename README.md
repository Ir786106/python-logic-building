## 📂 Repository Structure & Topics Covered 📚

### 🛠️ 1. Python Basics (`01_Basics/`) 🧱

Is folder mein Python ke fundamental concepts aur data types par practice ki gayi hai. Yahan basic syntax aur user input ko handle karne ka tareeka seekha gaya hai:

* 🔹 **`input.py`**: User se data lena aur mathematical logic banana (jaise swapping numbers aur time conversion). 🧮
* 🔹 **`string_method.py`**: Text data ko professional tareeke se handle karna, maslan `.split()`, `.replace()`, aur `.strip()` ka use. 📝
* 🔹 **`typcasting.py`**: Data types (jaise Integers aur Strings) ko aapas mein convert karna aur concatenate karna. 🔄
* 🔹 **`numbers_1.py`**: Escape characters (`\n`, `\t`) aur multiple variables ko ek sath print karna. 🖨️

### 🔀 2. Conditional Logic (`02_If_Else_Logic/`) ⚖️

Is folder mein real-world decision making, nested logic, aur complex logical operators (`and`, `or`) ka use kiya gaya hai. Yeh scripts business rules aur security ko handle karti hain:

* 🔸 **`if-else-Task-1.py`**: E-commerce Checkout System. Shehar (City) 🏙️, VIP customer status 🌟, aur cart total 🛒 ke hisaab se automated discount 💸 aur free delivery 🚚 calculate karna.
* 🔸 **`nested-if.py`**: Role-Based Authentication. Admin 👑 aur Customer 👤 roles ko pehchanna aur unki access limit set karna. 🚪
* 🔸 **`learning-nested-if.py`**: Bank ATM Simulation. Secure PIN verification 🔑 aur account balance checking 💳 ka nested logic.
* 🔸 **`if_else.py`**: Eligibility Systems. Age restrictions 🔞 aur driving license verification 🪪.
* 🔸 **`Free-Delivery.py`**: Basic Login Flows. Username/Password check 🛡️ aur minimum purchase amount validation 📊.
* 🔸**`warehouse_security.py`**: 🛡️ Advanced Security Portal featuring Multi-Factor Authentication (PIN verification) 🔑, automated Account Status monitoring 🚫, and specialized Role-Based Order Management 💼 for Managers & Staff.

## 🚀 How to Run the Code 💻

Agar aap in scripts ko apne system par run karna chahte hain, to yeh steps follow karein:

1. Repository ko clone karein ya direct download karein.
2. VS Code ya kisi bhi IDE mein main folder open karein.
3. Terminal mein specific file run karein, maslan: `python 02_If_Else_Logic/if-else-Task-1.py`
